An unofficial Ghostty companion

Context for the terminal tabs that all started looking the same.

I work primarily from the CLI. It lets me follow work across repositories and machines while staying remarkably light, but several long-running sessions quickly become visual clutter. This is the small fix I use.

A fresh Ghostty tab receives a stable color. The repository comes from the current Git root; the task and state are set explicitly, either by me or by the agent working in that session. The narrow bands are ordinary tmux formats. Nothing runs in the background and nothing leaves the machine.

Try it

Clone the source, put its command on your path, and source the shell hook from ~/.zshrc or ~/.bashrc.

git clone https://github.com/vipr8/ghostty-context-tabs \
  ~/.local/share/ghostty-context-tabs

export PATH="$HOME/.local/share/ghostty-context-tabs/bin:$PATH"
source "$HOME/.local/share/ghostty-context-tabs/shell/context-tabs.sh"

If you use tmux, source the included format file from ~/.tmux.conf, then give the current session a short human name:

source-file ~/.local/share/ghostty-context-tabs/tmux/context-tabs.conf

context-tabs set --task "Trace cache miss" --state working --tool Codex

Small on purpose

Ghostty already understands the OSC sequences for changing a running terminal’s foreground, background, cursor and title. tmux already knows how to render context. This joins those pieces without introducing an account, daemon, telemetry service or another workspace to maintain.

The source, exact configuration, privacy notes and removal instructions live in the GitHub repository.

Made by Avisek Das after too many identical terminal tabs. Unofficial and not affiliated with the Ghostty project.
